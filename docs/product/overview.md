# Product Overview

## Vision

Linear-inspired таск-трекер для РФ рынка. Два ключевых отличия от существующих решений:
1. **ИИ как центр системы** — не надстройка, а ядро. API-first подход: UI для людей, API/MCP для ИИ-агентов, оба — first-class citizens.
2. **РФ интеграции** — мессенджеры (Пачка, Telegram), git-хостинги (GitFlic, GitLab), российские платежи.

## Problem

- Дейлики, ручное перемещение карточек по доскам и прочая церемония замедляют работу, не давая реальных преимуществ.
- Доска с карточками — лишь способ **представления** работы, а не **управления** ей.
- В эру ИИ важно записывать все задачи с контекстом — чтобы ИИ мог с ними работать.
- Существующие инструменты не предоставляют ИИ-агентам полноценный доступ к управлению задачами.

## Target Audience

- Малый и средний бизнес, команды от 3 до ~50 человек.
- Роли: разработчики, тимлиды, продакт-менеджеры — для всех участников команды.

## AI Capabilities

- **API/MCP для ИИ-агентов** — любой ИИ (свой или внешний) может управлять системой: создавать, обновлять, декомпозировать задачи.
- **Проработка задач с ИИ** — ИИ помогает формулировать, декомпозировать и уточнять задачи.
- **Делегирование задач агентам** — задачи можно назначать ИИ-агентам (через интеграции с Cursor, другими coding agents).
- Конкретные ИИ-фичи будут определяться по ходу разработки.

## Business Model

SaaS подписка:
- **Free tier** — бесплатный базовый доступ.
- **Paid** — оплата за каждого члена команды.
