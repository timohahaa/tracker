# Auth

## MVP

### Registration

- Регистрация по email + пароль.
- При регистрации создается workspace (или пользователь присоединяется к существующему по инвайту).
- Валидация email (формат), пароль — минимум 8 символов.

### Login

- Вход по email + пароль.
- Сессия на основе токена (JWT или session-based — решение в tech docs).

### Invite Flow

- Owner/Admin приглашает участника по email.
- Приглашенный получает ссылку, регистрируется (или логинится) и попадает в workspace.

### Roles

| Role | Capabilities |
|------|-------------|
| Owner | Все: управление workspace, billing, участники, команды, проекты, задачи. Один на workspace. |
| Admin | Управление командами, участниками, проектами. Не может удалить workspace или менять billing. |
| Member | Работа с задачами, проектами. Не может управлять участниками workspace. |

## Post-MVP

- OAuth (Google, GitHub, GitLab).
- SSO (SAML) для энтерпрайза.
- 2FA.
- Управление сессиями (список активных, отзыв).
